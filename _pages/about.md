This site indexes talks about cloud native security: containers, Kubernetes, supply chain, identity and runtime security. The talks come from the security tracks at KubeCon + CloudNativeCon and from CloudNativeSecurityCon and Cloud Native Security Day. Every talk page has the published abstract, a link to the Sched entry and the recording, where there is one.

## Adding a talk

Talks from the KubeCon security tracks and the security conferences are added by an automated import. To add a talk from another venue, open a pull request on [GitHub](https://github.com/raesene/Cloud-Native-Security-Talks) that adds a file to `_posts/`. The README explains the format.

## Colophon

Set in Archivo and IBM Plex Mono. The layout follows the [Quadro](https://katagami.ai/language/en-019f707a-483d-7733-974a-4617c7566e66) design language, and the plates are drawn in the [Glacis Ink](https://katagami.ai/art-styles/en-019ef8ac-0a88-7910-bc05-845eed0508fe) style.
